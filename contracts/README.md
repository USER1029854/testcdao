# Archived contract sources

Verified on-chain contract source, fetched from the block explorer (Etherscan V2 API) and stored as real file trees, one folder per contract. Each contract folder contains:

- `source/` — the full verified source tree, exactly as submitted for verification (multiple files/directories preserved, not flattened)
- `abi.json` — the verified ABI, when available
- `NOTES.md` — chain, address, proxy status (with implementation source resolved and saved alongside if applicable), and verification status
